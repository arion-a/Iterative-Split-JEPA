Then every sample (both rows of each pair) goes through the same bend and the encoder and becomes a dot in the embedding space. The splitter sees only these dots and which two dots form a pair. It does not see a, b, c.

Step 2. Rung 1 in the embedding space (all dots, whitened to a round ball)

Each pair is two dots The two dots differ along one direction: the direction in which the embedding moves when a changes.
Subtract every pair The differences stretch only along a's direction. Eigendecomposition reads off that direction: V1.
Remove V1, keep the rest (H1) A direction is gone; what remains is the part of the embedding that did not change between the pair.

Step 3. Rung 2, inside what is left (H1: only the b and c directions)

Subtract rung-2 pairs, seen in H1
Remove V2: what is left is c The last direction is the group that never changed between the pairs.
